Nonnon Nyaurism 


	.WAV Tweaker

		drop to load

		[ Supported Format ]

			+ .WAV
			+ some .MP3 or .M4A files are available (load only)


	Limitation

		full-scalable but suit for small sound effect files

			+ maybe too much heavy with large files

		no seed generation

			+ you can use your smartphone, MIDI recorder apps or AI to make seed

		window (plotter area) is non-resizable

			+ samples to display will be skipped (details are lost)


	Plotter

		Upper : Left Channel
		Lower : Right Channel

		Input

			click
				set/reset position

			double-click
				select all

			drag
				select area

				partial : re-selection (frame only moved)

			Shift
				move data

			Command
				select one of Left or Right

				+ apply a channel under cursor

			Backspace
				delete

			F2
				rename by date

		Menu

			Undo
				undo

			Select All
				select all

			Unselect
				release selection

				+ you can click empty area in a window to unselect

			Cut
			Copy
			Paste
			Overwrite/Mix
				edit

			Mute
				set zero

			Monaural
				sync L/R channels

			Copy Left to Right
			Copy Right to Left
				make monaural compatible data

			Fade-In
			Fade-Out
				fade effect

			Smoother
				Savitzky-Golay Filter

			Overdirve
				Distortion-like Filter

			Tremolo
				LFO Filter : 3 Hz

			White Noise
			Pink Noise
				noise generator

					+ mix always


	Icon Buttons

		Mute
			set zero

		Mix
			mix on/off

			+ drop and effects behavior will change

			+ you can do Delay, Feedback, Chorus and etc.

		Stop
			stop playback

		Play / Pause
			playback / pause

		Equalizer
			open a graphic equalizer window

			[ How to Use Analyzer ]

			1 : press "Analyze" button
			2 : set sliders zero if the bands are used
			3 : press "Apply" to make sound clear

		Resizer
			resize whole data by msec.

		Formatter / Save
			save as specified format

	Slider

		L/R
			normalizer
